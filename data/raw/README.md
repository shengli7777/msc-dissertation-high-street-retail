# Raw data

Place the following local input files here before running the analysis:

- OpenLocal retail property dataset, parquet format
- ONS Local Authority District boundary shapefile components:
  - .shp
  - .shx
  - .dbf
  - .prj
  - .cpg if available

The raw OpenLocal dataset is not included in this repository because it was provided for dissertation analysis and may not be publicly redistributable.
